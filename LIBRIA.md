# Libria

Venho por este projeto poder incentivar na educação de libras pelo nosso País e acessibilidade, com uso da tecnologia para tradução simplificada com uso de IA's. Permitindo mais acessibilidade e alcance a todos de forma gratuita ao meu modelo;

```
A = [Educação de qualidade, Redução das desigualdades, Paz, justiça e instituições eficazes] 

--> B [Acessibilidade a um modelo de tradução de libras por IA's]

B --> C [Dentro de 3 meses, compreender o campo de estudo]

C --> D [Identificar os dados que serão trabalhados, usado datassets disponiveis pela internet]

D --> E [Listar os recursos necessários, como API's, e bibliotecas gráfica para extração e tratamento dos dados]

E --> F [Desenvolvimento do projeto, partindo de modelos pré-treinados]
    
F --> G [Fase 1: Desenvolver uma própria rede neural capaz de compreender e classificar objetos, dando-os rótulos de classes]

F --> H [Fase 2: Desenvolver outro modelo capaz de entender os gestos de libras]

F --> I [Fase 3: Desenvolver um modelo generativo para os textos que serão exibidos para a tradução]

I --> J [Entrega do Projeto]
