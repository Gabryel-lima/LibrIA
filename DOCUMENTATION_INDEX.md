## 🚀 Fluxo Recomendado

### Primeiro Acesso (15 min)
1. README.md - Entender o projeto
2. CONTRIBUTING.md - Saber como ajudar

### Setup (30 min)
1. docs/DEVELOPMENT.md - Instalar localmente
2. make setup - Executar automação

### Primeira Contribuição (2-3 h)
1. docs/PULL_REQUEST_GUIDE.md - Como fazer PR
2. Crie feature branch
3. Faça mudanças
4. Envie PR

### Code Review
1. Responda feedback
2. Atualize código
3. Aprove e merge!
