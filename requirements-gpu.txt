# LibrIA - Suporte a GPU (Linux, NVIDIA)
# Uso: pip install -r requirements.txt -r requirements-gpu.txt   (ou: make install-gpu)
#
# - PyTorch: o wheel do PyPI para Linux já traz as bibliotecas CUDA que usa
#   (CUDA 13 no torch 2.13). Nada a fixar aqui.
# - TensorFlow 2.16.1: o extra oficial [and-cuda] instala exatamente as
#   bibliotecas que ele exige (CUDA 12.3 e cuDNN 8.9).
#
# A versão anterior deste arquivo fixava as bibliotecas CUDA 12.4 / cuDNN 9 do
# torch 2.5.1: não serviam ao torch 2.13 (que traz as próprias) e conflitavam
# com o cuDNN 8.9 que o TensorFlow 2.16.1 exige. Ver docs/SEGURANCA.md.
tensorflow[and-cuda]==2.16.1
