# 📜 Código de Conduta para Colaboradores

## Nosso Compromisso

No LibrIA, estamos comprometidos em fornecer um ambiente acolhedor e inclusivo para todos os colaboradores, independentemente de:

- Idade
- Deficiência
- Etnia
- Identidade de gênero
- Nível de experiência
- Nacionalidade
- Aparência pessoal
- Raça
- Religião
- Identidade sexual

## Nossos Padrões

### Comportamento Esperado

- Ser respeitoso e inclusivo com todos
- Usar linguagem acolhedora
- Estar aberto a críticas construtivas
- Focar no melhor para a comunidade
- Mostrar empatia com outros colaboradores
- Reconhecer o trabalho alheio

### Comportamento Inaceitável

- Assédio sexual, bullying ou discriminação
- Trolling, insultos ou comentários depreciativos
- Spam ou promoção não autorizada
- Revelação de informações privadas ("doxxing")
- Qualquer conduta que considere inapropriada

## Implementação

### Relatar Violações

Se presenciar ou sofrer violações deste código:

1. **Não responda** com agressividade (pode piorar)
2. **Reporte** para: `conduct@LibrIA.dev` ou moderadores
3. **Documentar** se possível (screenshots, etc)

### Confidencialidade

Todos os relatos são tratados com confidencialidade. A identidade do denunciante será protegida.

### Investigação

Violarções serão investigadas:
- Dentro de 48 horas
- Com imparcialidade
- Com oportunidade de resposta do réu

### Consequências

Dependendo da severidade:

1. **Aviso** - Comunicação alertando sobre comportamento
2. **Suspensão Temporária** - 24h - 30 dias sem acesso
3. **Ban Permanente** - Remarcação de acesso

## Escopo

Este código se aplica em:

- Repositório GitHub
- Issues e Pull Requests
- Discussions
- Discord/Chat comunitário
- Eventos e conferências
- Qualquer espaço oficial do projeto
